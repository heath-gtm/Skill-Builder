# Customer doc generator

Turn what you know about an account into a document you can send. The move is dogfood: you sell the doc product by sharing a great doc. One tailored doc per account, built from real context, never generic.

## Inputs
The account (name, domain), and whatever context is available: CRM stage and ARR, product usage, the buying committee, meeting notes, the value hypothesis. Pull from the connected stack where possible. Ground every claim in real context; if a fact is not known, leave it out rather than inventing it.

## Pick the doc type (from the template library)
- **Deal room:** for an active opportunity. Hero (account, stage, the ask), the business case, a mutual action plan timeline, the buying committee, references.
- **Account plan:** for a strategic read. Hero (account, ARR, verdict, owner), buying-committee card wall, whitespace decision table, next move, references.
- **Mutual action plan:** the dated path to signed, as a timeline with owners on both sides.

## The build
Use the matching template, prune to this account, build the substance via the MCP, finish in the UI, and ship-check before sharing. Brand it for the customer: their name in the hero, a clean cover, a subtitle that states the value in one line. Interaction mode View, unless the champion needs to edit the shared action plan (then Edit).

## Make it yours
Fork it. Wire it to your CRM and usage source, set your deal-room and account-plan sections. The point is a tailored doc per account, fast, that a rep is proud to send. Built by an operator. Customize it, break it, make it better.
