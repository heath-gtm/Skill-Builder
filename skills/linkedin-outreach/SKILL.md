# LinkedIn-Outreach

## What this does
Writes the LinkedIn touches that fit the moment: a connection note that earns the accept without pitching, and follow-ups that lead with something useful. It reads where the prospect is, never messaged, engaged with your stuff, or gone dark, and matches the message to that state instead of sending the same nudge to everyone.

## What you'll need
You do not need to connect anything to get value today. Paste the prospect and where things stand, and it runs now. Connect the tools below and it grounds the touch in the account and its history.

- Works today with: a name, a title, a company, and the state of the thread (cold, engaged, quiet). Paste it and go.
- More powerful connected to a CRM: it reads the account and any prior touches across channels so the note fits the whole relationship.
- Sharper with an enrichment tool: pulls the role and recent activity so the connection note references something real.
- Sharper with a sequencer: lets you fold the LinkedIn steps into a multi-channel cadence instead of running them by hand.

## How this runs at your connection level
This skill is never reliant on a connector. It runs on what you paste today and gets sharper as you connect tools. It never invents a shared connection or a post the prospect did not make. A missing detail is a question it asks, not a claim it fabricates.

- **Bring your data**: paste the prospect and the thread state. The skill writes the note and the follow-ups now, grounded only in what you gave it.
- **Connect your tools**: the same skill reads the account history so the touch references real prior contact and picks up where the relationship left off.
- **Just exploring**: no prospect yet? Get the note templates, the state map, and a worked example on a sample persona, so you see the shape before you send.

Every run ends with the one thing that would make the next touch sharper, a signal to add or a tool to connect.

## Customize this for yourself
This was built for B2B social selling into a named persona. Set these to your motion:

| Set this | What it is | Default / Example |
|---|---|---|
| PERSONA | who you are reaching | VP, manager, individual contributor |
| OFFER | the one problem you solve | stated plainly, not pitched |
| STATE | where the thread is | cold, engaged, gone quiet |
| VALUE_ASSET | the useful thing you lead with | a resource, a take, a relevant intro |
| CONNECT_STYLE | note or no note on the request | short note by default |
| CRM | your CRM connector | a CRM you already run |
| SEQUENCER | where social steps join the cadence | a sequencer you already run |

Reach any persona you like. The skill matches the message to the state of your thread, not a one-size nudge.

## The method

### Match the message to the state
Three states, three moves. **Cold**: a connection note that gives a reason to accept and pitches nothing. **Engaged** (they liked, viewed, commented): a warm opener that references the real interaction and offers something useful. **Gone quiet**: a low-pressure re-open that changes the angle instead of repeating the last ask. Same person, different message.

### The connection note that earns an accept
Under 300 characters, no pitch, one honest reason you want to connect: a shared interest, a relevant topic, a genuine reaction to their work. The connect is not the ask. It is permission to have a conversation later.

### Value-first follow-ups
Every follow-up leads with something for them before anything for you: a resource, a relevant example, a useful observation, a light question. "Just following up" and "circling back" are banned. If a touch has nothing to give, it does not send.

### Re-opening a quiet thread
When a thread goes dark, do not repeat the ask. Change the lens: a new angle on the problem, a fresh resource, or an honest "should I close the loop?" that gives them an easy, face-saving exit. A clean permission to say no often gets a reply.

### Channel manners
LinkedIn is not email. Shorter, more human, no formatted signatures, no wall of text. Match the reader's register, and never automate to the point it reads like a bot.

## Quality gates
- The connection note pitches nothing and stays under 300 characters.
- Every follow-up leads with value before any ask. No "just following up."
- The message matches the stated thread state, never a generic nudge.
- A quiet-thread re-open changes the angle and offers a graceful exit.

## Output (example)
```
LINKEDIN · Head of Support · state: engaged (liked 2 posts)

Connection note (cold version, <300 char):
"Hi [name], I keep seeing support leaders wrestle with [problem].
You clearly think about this space. Would like to follow along and
trade notes, no pitch."

Engaged follow-up (after accept + likes):
"Thanks for the connect, and for reading. Since [topic] is on your
radar, here is a short teardown of how a few teams handle it: [link].
Curious if any of it maps to your world."

Gone-quiet re-open (14 days later):
"No worries if this is not a now problem. Came across [resource]
and thought of your team. Want me to close the loop, or keep
sending the odd useful thing?"
```

## Where the inputs come from
PERSONA, OFFER, and STATE are yours to set; the 300-character note ceiling and the three-state model are defaults that suited a relationship-first social motion, not laws. A higher-volume motion can simplify the states. The structure holds. The inputs are yours.
