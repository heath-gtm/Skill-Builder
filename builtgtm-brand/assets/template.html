02 / The steps component

How a document gets built.

  1. Start from the shell. Every Studio doc runs through the canonical skeleton with every component wired. Never build the scaffold from memory.
  2. Pick only what the document needs. A brief might be eyebrow, H1, cobalt rule, lede, facts grid, two sections, callout, footer.
  3. Write the copy in the voice. Plain declaratives. Receipts. The visual system and the voice rules ship together or not at all.
  4. Run the check. No off-palette colors, cobalt used deliberately, sections numbered, hard shadows on cards, mobile breakpoint present.
